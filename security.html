Security

Clear context. Clear permissions.

AI Workspace is designed so you can always tell what the AI can see, who can see your work, and where an answer came from.

AI Workspace is an interactive product concept. This page describes how its controls are designed, and makes no claims about certifications or compliance.

Design principles

Boundaries you can read.

Each control is built to be understood at a glance, so nobody has to guess what is private, what is shared, and what the AI used.

  • Private by default

    New projects, conversations, and documents start visible only to you.

  • Visibility you can read

    Every item shows plainly whether it is private, workspace, or shared by link.

  • Sources stay attributed

    Answers point back to the passages and files they used, so claims can be checked.

  • Roles, not guesswork

    Owner, Admin, and Member each have a defined, documented set of actions.

  • Shared links, bounded

    A shared link exposes only the item you chose, never the project around it.

  • Honest about AI

    Generated work carries a disclosure, and demo models are labeled as illustrative.

Sharing

Three levels. No surprises.

Visibility is set per item and always shown next to it, so sharing is a decision you can see.

  1. 01

    Private

    Only you can see it. This is the starting point for everything you create.

  2. 02

    Workspace

    Everyone in the workspace can find and open it, according to their role.

  3. 03

    Shared link

    Anyone with the link can view that one item. Private context around it stays private.

Roles

Who can do what.

Three roles cover everyday collaboration, and no role can open another person’s private work.

Actions available to the Owner, Admin, and Member roles
Action Owner Admin Member
Workspace
Rename the workspace and manage billing Yes No No
Invite and remove members Yes Yes No
Change member roles Yes Yes No
Work
Create projects and conversations Yes Yes Yes
Share your own work Yes Yes Yes
Comment on shared work Yes Yes Yes
Privacy
Open another person’s private items No No No

Common questions

Plainly answered.

  • Only you, until you change it. Each item shows its visibility, and moving it to the workspace or a shared link is always an explicit choice.

  • Only the item it points to. Other items in the project, its instructions, and its private sources are not part of what the link shows.

  • No. AI Workspace is a design and engineering concept. It describes how permissions and sharing could work, and does not claim any certification or compliance.
